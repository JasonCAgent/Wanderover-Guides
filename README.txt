HOW THIS SITE IS ORGANIZED
--------------------------
assets/          Shared look and features for every guide. Change once, every property updates.
back-inn-black/  Back Inn Black's guide. Guests visit  <your-site>/back-inn-black/
_template/       Blank starter. Copy this folder and rename it for each new property.
index.html       Plain landing page (doesn't list your properties).
robots.txt       Asks search engines not to index the guides (they contain wifi details).

TO EDIT A GUIDE: open that folder's index.html in any text editor and change the
"PROPERTY DATA" block near the bottom. Then re-upload the whole folder.
